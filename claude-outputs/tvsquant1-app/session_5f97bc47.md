### CRIT-1: BundleError.file_path accepts wrong type (violates type safety)
**Location:** `data/exceptions.py:94`

The `BundleError.__init__` signature is:
```python
def __init__(self, file_path: str, context: str) -> None:
```

But the test passes a `Path` object:
```python
def test_bundle_error_with_path_object(self):
    path = Path("/path/to/bundle")
    error = BundleError(path, "Test error")  # Path object, not str!
```

**Why it works:** `self.file_path = str(file_path)` converts it silently.  
**Problem:** Type hint lies - says `str` but accepts `Path`. This violates the project-context.md type hint requirements. Should be `file_path: str | Path`.
