## How StrategyAdapter Translates Signals to Zipline Orders

### The Signal → Order Flow

```
Signal.calculate(ohlcv_df)  →  {symbol: value}  →  zipline order calls
         ↓                           ↓                      ↓
   Pure logic layer           Signal values         Execution layer
                              (-1, 0, +1)
```

### Step-by-Step Breakdown

**1. Data Preparation** (`_build_ohlcv_dataframe`)

When zipline calls `handle_data(context, data)`, the adapter first retrieves historical price data:

```python
# strategies/base.py:204-238
def _build_ohlcv_dataframe(self, data, symbols, lookback=None):
    assets = [zp_symbol(s) for s in symbols]
    
    ohlcv_data = {}
    for field in ['open', 'high', 'low', 'close', 'volume']:
        history = data.history(
            assets=assets,
            fields=field,
            bar_count=lookback,  # e.g., 21 bars
            frequency='1d'
        )
        ohlcv_data[field] = history
    
    return pd.DataFrame(ohlcv_data)
```

**2. Signal Calculation**

The adapter passes this DataFrame to the Signal's `calculate()` method:

```python
# strategies/base.py:187
signals = context.signal.calculate(ohlcv_df)
# Returns: pd.Series({'VND': 1, 'SSI': -1, 'HPG': 0})
```

**3. Order Translation** (`handle_data`)

The core translation logic maps signal values to zipline order calls:

```python
# strategies/base.py:190-199
for sym in context.symbols:
    asset = zp_symbol(sym)
    sig_value = signals.get(sym, 0)  # Default to hold
    
    if sig_value > 0:  # BUY signal
        order_target_percent(asset, context.position_size)
        
    elif sig_value < 0:  # SELL signal
        if context.allow_short:
            order_target_percent(asset, -context.position_size)
        else:
            order_target_percent(asset, 0)  # Just close
            
    # sig_value == 0: HOLD - no action
```

### Translation Table

| Signal Value | allow_short=False | allow_short=True |
|-------------|-------------------|------------------|
| `+1` (buy) | `order_target_percent(asset, 0.5)` | `order_target_percent(asset, 0.5)` |
| `0` (hold) | No order placed | No order placed |
| `-1` (sell) | `order_target_percent(asset, 0)` | `order_target_percent(asset, -0.5)` |

*Assuming `position_size=0.5` (50% of portfolio)*

### What `order_target_percent` Does

This zipline function automatically calculates and places the necessary orders to reach the target portfolio allocation:

```python
# If currently 0% in VND and target is 50%:
order_target_percent(symbol('VND'), 0.5)
# → Zipline calculates shares needed and places BUY order

# If currently 50% in VND and target is 0%:
order_target_percent(symbol('VND'), 0)
# → Zipline calculates shares to sell and places SELL order

# If currently 50% in VND and target is -50% (short):
order_target_percent(symbol('VND'), -0.5)
# → Zipline sells all shares + borrows to short
```

### Example Scenario

```python
# Setup
signal = MomentumSignal(lookback=20)
adapter = StrategyAdapter(
    signal=signal,
    symbols=['VND', 'SSI'],
    position_size=0.5,    # 50% per symbol
    allow_short=False
)

# On bar 2024-03-15, signal.calculate() returns:
# {'VND': 1, 'SSI': -1}

# Adapter translates to:
order_target_percent(symbol('VND'), 0.5)   # Go 50% long VND
order_target_percent(symbol('SSI'), 0)     # Close SSI position
```

### Error Handling

If the Signal raises a `SignalError`, the adapter wraps it as `AdapterError` to preserve context:

```python
except SignalError as e:
    raise AdapterError(self.signal.name, str(e)) from e
# → "StrategyAdapter (MomentumSignal): DataFrame is empty"
```

This separation keeps the Signal layer pure (no zipline dependencies) while the Adapter handles all execution details.
