## 🔴 CRITICAL ISSUES

### Issue #1: Bundle Naming Inconsistency - Multi-Symbol Import Broken
**File:** `tvsquant1/cli/main.py:152-154`
**Severity:** CRITICAL

The non-force path calls `ensure_bundle_fresh(symbol, csv_path, bundle_name)` passing the same bundle name (e.g., `"tvsquant"`) for ALL symbols. This causes each symbol to **overwrite** the previous bundle!

```python
# Current code (BROKEN):
else:
    status = ensure_bundle_fresh(symbol, csv_path, bundle_name)  # Same "tvsquant" for all!
```

But the `--force` path correctly uses per-symbol naming:
```python
if force:
    bundle_name_for_symbol = f"{bundle_name}_{symbol.lower()}"  # Correct: "tvsquant_test1"
```

**Evidence:** Story Dev Notes (lines 527-529) specify:
> - Bundle naming pattern: `tvsquant_{symbol.lower()}`

**Impact:** When importing 5 CSV files without `--force`, only the LAST symbol's data survives. All previous symbols are overwritten.
