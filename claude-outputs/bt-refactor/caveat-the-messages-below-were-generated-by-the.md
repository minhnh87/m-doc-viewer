### 4. Design Patterns được áp dụng

| Pattern | Mục đích | Áp dụng cho |
|---------|----------|-------------|
| **Repository** | Tách logic persistence | Order, Trade, Position repos |
| **Factory** | Tạo object linh hoạt | DataLoaderFactory |
| **Chain of Responsibility** | Tách validation | BuyingPower → SellingPos → PriceRange → ... |
| **Unit of Work** | Transaction management | Atomic order processing |
| **Dependency Injection** | Loose coupling | Toàn bộ services |
| **Circuit Breaker** | Fault tolerance | External API calls |
| **Decorator** | Cross-cutting concerns | Retry, timing, caching |

```python
# shared/db.py (MỚI - ~40 dòng)
from psycopg2 import pool
from contextlib import contextmanager
from .config import Config

_pool = None

def get_pool():
    global _pool
    if _pool is None:
        _pool = pool.ThreadedConnectionPool(
            minconn=2,
            maxconn=10,
            host=Config.DB_HOST,
            port=Config.DB_PORT,
            database=Config.DB_NAME,
            user=Config.DB_USER,
            password=Config.DB_PASSWORD
        )
    return _pool

@contextmanager
def get_connection():
    """Dùng thay cho psycopg2.connect() ở mọi nơi"""
    conn = get_pool().getconn()
    try:
        yield conn
        conn.commit()
    except Exception:
        conn.rollback()
        raise
    finally:
        get_pool().putconn(conn)

# Cách dùng:
```

#### **Vấn đề 5: Không có retry** → Simple decorator

```python
# shared/retry.py (MỚI - ~30 dòng)
import time
import logging
from functools import wraps

logger = logging.getLogger(__name__)

def retry(max_attempts=3, delay=1, backoff=2):
    """Simple retry decorator"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            last_error = None
            for attempt in range(max_attempts):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    last_error = e
                    wait = delay * (backoff ** attempt)
                    logger.warning(f"{func.__name__} failed (attempt {attempt+1}), retrying in {wait}s: {e}")
                    time.sleep(wait)
            raise last_error
        return wrapper
    return decorator

# Cách dùng:
# @retry(max_attempts=3)
```

```python
# shared/cache.py (MỚI - ~50 dòng)
import redis
import pickle
from .config import Config

_redis = None

def get_redis():
    global _redis
    if _redis is None:
        _redis = redis.Redis(
            host=Config.REDIS_HOST,
            port=Config.REDIS_PORT,
            decode_responses=False
        )
    return _redis

def cache_get(key):
    """Get from cache, return None if not found"""
    data = get_redis().get(key)
    return pickle.loads(data) if data else None

def cache_set(key, value, ttl=3600):
    """Set with TTL (default 1 hour)"""
    get_redis().setex(key, ttl, pickle.dumps(value))

def cache_delete(pattern):
    """Delete keys matching pattern"""
    for key in get_redis().keys(pattern):
        get_redis().delete(key)
```

#### 1. Mode Interface (`core/modes/base.py`)

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from datetime import date
from typing import Optional
import pandas as pd

@dataclass
class ModeConfig:
    """Config chung cho tất cả modes"""
    start_date: date
    end_date: Optional[date] = None
    accounts: list = None
    wait_realtime: bool = False
    cleanup_before_run: bool = False

class BaseMode(ABC):
    """Interface cho tất cả modes"""
    
    def __init__(self, config: ModeConfig):
        self.config = config
    
    @property
    @abstractmethod
    def name(self) -> str:
        """Tên mode: backtest, forward, live"""
        pass
    
    @abstractmethod
    def load_historical_data(self, tickers: list) -> pd.DataFrame:
        """Load dữ liệu lịch sử"""
        pass
    
    @abstractmethod
    def load_realtime_data(self, tickers: list) -> pd.DataFrame:
        """Load dữ liệu realtime (nếu có)"""
        pass
    
    @abstractmethod
    def should_wait_market_time(self) -> bool:
        """Có cần chờ market check time không?"""
        pass
    
    @abstractmethod
    def get_order_adapter(self):
        """Trả về adapter để save orders"""
        pass
    
    @abstractmethod
    def cleanup(self, accounts: list):
        """Cleanup data trước khi chạy (nếu cần)"""
        pass
    
    def prepare_data(self, tickers: list) -> pd.DataFrame:
        """Template method: Chuẩn bị data theo mode"""
        # 1. Load historical
        df = self.load_historical_data(tickers)
        
        # 2. Load realtime nếu cần
        if self.config.wait_realtime:
            df_realtime = self.load_realtime_data(tickers)
            if not df_realtime.empty:
                df = pd.concat([df, df_realtime])
        
        return df
```

```python
            start_date=self.config.start_date,
            end_date=datetime.now().date()
        )
    
    def load_realtime_data(self, tickers: list) -> pd.DataFrame:
        # Chờ market check time nếu cần
        if self.should_wait_market_time():
            self._wait_for_market_time()

        target = datetime.now().replace(hour=14, minute=0, second=0)
        now = datetime.now()
        if now < target:
            wait_seconds = (target - now).total_seconds()
            print(f"Waiting {wait_seconds/60:.1f} minutes for market check time...")
            time.sleep(wait_seconds)
    
    def get_order_adapter(self):
        return self.order_adapter
    
    def cleanup(self, accounts: list):
        if self.config.cleanup_before_run:
            for account in accounts:
                cleanup_selective(account, from_date=datetime.now().date())
```

```python
class StrategyRunner:
    """Runner không cần biết chi tiết mode"""

        mode_config = ModeConfig(

            end_date=kwargs.get('end_date'),
```

```
       ├── ModeFactory.create(mode_name)
       │         │
       │         ├── BacktestMode
       │         ├── ForwardMode
       │         └── LiveMode
       │
       ▼
  mode.prepare_data()     ← Mỗi mode tự biết load gì
  mode.get_order_adapter() ← Mỗi mode tự biết save đâu
  mode.cleanup()          ← Mỗi mode tự biết cleanup gì
       │
       ▼
  BaseStrategy.run()
       │
       ▼
  order_adapter.save()    ← CSV hoặc DB tùy mode
```

| Cũ (`CORE_SOURCE`) | Mới (`--mode`) |
|-------------------|----------------|
| `api` | `backtest` |
| `bt_db` | `backtest` (với DB storage) |
| `db` | `forward` |
| `fw_db` | `live` |

## Phân tích các mode hiện tại

Dựa trên code analysis, đây là **hành vi thực tế** của từng mode:

| Mode cũ | Data Source | Order Storage | Chờ Realtime | Mục đích thực tế |
|---------|-------------|---------------|--------------|------------------|
| `api` | Trino + FiinQuant (historical) | **CSV files** | ❌ Không | Test chiến lược với data lịch sử |
| `bt_db` | Trino (date range) | PostgreSQL | ❌ Không | Test chiến lược với data lịch sử |
| `db` | Trino (historical) | PostgreSQL | ❌ Không | Simulate forward, không có realtime |
| `fw_db` | Trino + **Realtime** | PostgreSQL | ✅ **Có (14:00)** | Chạy thật, chờ data realtime |

## Tại sao `api` → `backtest`?

Mặc dù tên là "api", nhưng mode này:

1. **Không giao dịch thật** - chỉ output ra CSV
2. **Không chờ realtime** - chạy ngay với data historical
3. **Dùng để test chiến lược** - giống backtest

```python
# QPTPMAROCBOSS2W.py - api mode
if CORE_SOURCE == 'api':
    # Load historical data
    # Output to CSV files (buy_signal_trades.csv, sell_signal_trades.csv)
    # KHÔNG chờ market check time
```

**→ Bản chất là backtest, chỉ khác output format (CSV)**

## Tên "api" gây hiểu nhầm

Tên `api` ám chỉ nguồn data (FiinQuant API), **không phải** mục đích sử dụng.

Trong khi:
- `fw_db` mới là mode **thực sự live** (chờ 14:00, lấy realtime)

| Mode cũ | Mapping theo mục đích | Mapping theo data source |
|---------|----------------------|-------------------------|
| `api` | `backtest` | `backtest-api` |
| `bt_db` | `backtest` | `backtest-db` |
| `db` | `forward` | `forward` |
| `fw_db` | `live` | `live` |

Hoặc giữ nguyên 4 modes như cũ, chỉ đổi tên rõ nghĩa hơn:
