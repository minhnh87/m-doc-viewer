## Historical Backtest Data Model

### 1. Source: Trino/Iceberg

**Tables được sử dụng:**
- `iceberg.dwh_atomic.dwh_market_prices_and_transactions_securities_daily_prices` - OHLCV gốc
- `iceberg.mart_common.fact_securities_daily_priceadjusted_history` - Giá adjusted

### 2. DataFrame Schema (từ TrinoDailyLoader)

| Column | Type | Description |
|--------|------|-------------|
| `ticker` | str | Mã chứng khoán (3 ký tự) |
| `transdate` | datetime | Ngày giao dịch |
| `price_opened` | float | Giá mở cửa (non-adjusted) |
| `price_closed` | float | Giá đóng cửa (non-adjusted) |
| `price_adj_opened` | float | Giá mở cửa adjusted (tính từ formula) |
| `price_adj_closed` | float | Giá đóng cửa adjusted |
| `price_reference` | float | Giá tham chiếu |
| `volume_total` | float | Tổng khối lượng |

**Formula tính `price_adj_opened`:**
```sql
CEIL((price_adj_closed - price_adj_closed * ((price_closed / price_opened) - 1)) / 50) * 50
```
