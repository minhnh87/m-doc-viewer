### Files Created

**1. `engine/__init__.py`**
- Package init that exports `BacktestRunner`

**2. `engine/runner.py`** 
- `BacktestRunner` class that handles:
  - Data loading from Trino (with FiinQuant for live modes)
  - Results/logs directory setup with timestamps
  - Cerebro configuration with data feeds
  - Strategy instantiation with proper parameters
  - Mode-specific data handling (`bt_db`, `db`, `fw_db`, `api`)
  - Fallback to CSV if DB fails
  - Filtering tickers with insufficient data

**3. `run.py`**
- CLI entry point with argument parsing
- Supports: `python run.py qpmmt_vn30 --mode bt_db`
- Options:
  - `--mode`: bt_db, db, fw_db, api
  - `--from-date`: Start date (YYYY-MM-DD)
  - `--to-date`: End date (YYYY-MM-DD)
  - `--cash`: Initial cash amount

### Usage Examples

```bash
# Run backtest with default date range
python run.py qpmmt_vn30 --mode bt_db

# Run with custom date range
python run.py qpmmt_vn30 --mode bt_db --from-date 2023-01-01 --to-date 2024-12-31

# Run in live forward mode
python run.py qpmmt_vn30 --mode fw_db
```

### Key Features
- Reuses existing data loaders (`TrinoDailyLoader`, `FiinDataLoader`)
- Reuses existing data feed (`CSVDataFeed`)
- Reuses existing strategy (`QPMMTStrategy`)
- Maintains backward compatibility with existing config
- Creates timestamped results directories
- Configures logging to both file and console
