## Logic của Strategy MomentumSignal

### Tổng quan

`MomentumSignal` là một strategy giao dịch dựa trên **momentum** (đà tăng/giảm giá). Ý tưởng cốt lõi: nếu giá đang tăng → tiếp tục mua; nếu giá đang giảm → bán.

### Công thức tính

```
momentum = (giá_hiện_tại / giá_n_ngày_trước) - 1
```

Với `n = lookback_period` (mặc định 20 ngày).

### Logic tín hiệu

| Momentum | Signal | Ý nghĩa |
|----------|--------|---------|
| > 0 | +1 | **Mua** - Giá đang tăng so với n ngày trước |
| < 0 | -1 | **Bán** - Giá đang giảm so với n ngày trước |
| = 0 | 0 | **Giữ nguyên** - Giá không đổi |
| NaN | NaN | Chưa đủ dữ liệu (n ngày đầu) |

### Flow xử lý (`momentum.py:71-120`)

1. **Validate dữ liệu**: Kiểm tra DataFrame có đủ cột OHLCV
2. **Lấy cột Close**: Hỗ trợ tên cột case-insensitive
3. **Tính momentum**: `close / close.shift(lookback_period) - 1`
4. **Chuyển thành signal**: Dùng `np.where` để vectorize (nhanh gấp 12x so với `.apply()`)

### Ví dụ minh họa

```
Ngày 1:  Giá = 100
...
Ngày 20: Giá = 105
Ngày 21: Giá = 110

Tại ngày 21:
  momentum = 110/100 - 1 = 0.10 (10%)
  → momentum > 0 → signal = +1 (MUA)
```

### Điểm mạnh/yếu

**Mạnh**: Logic đơn giản, dễ hiểu, chạy nhanh (vectorized numpy)

**Yếu**: 
- Chỉ dựa vào 1 chỉ báo (momentum)
- Không có stop-loss/take-profit
- Có thể bị whipsaw trong thị trường sideway
