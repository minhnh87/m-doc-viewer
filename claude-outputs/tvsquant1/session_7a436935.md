Bạn có thể chỉ định và update Python version ở các nơi sau:

## 1. **File `pyproject.toml`** (Nơi chính - đã có)

**Tại dòng 6** - Chỉ định Python version tối thiểu:
```toml
requires-python = ">=3.11"
```

Bạn có thể update thành:
- `">=3.11,<3.13"` - Cho phép 3.11 và 3.12
- `">=3.12"` - Yêu cầu tối thiểu 3.12
- `"==3.11.*"` - Chỉ cho phép 3.11.x

**Tại dòng 39** - Black formatter target version:
```toml
target-version = ['py311']
```

Nếu update lên Python 3.12, đổi thành `['py312']`

## 2. **File `.python-version`** (Cho pyenv - chưa có)

Tạo file này ở root directory để pyenv tự động switch version:
```bash
echo "3.11.9" > .python-version
```

Hoặc version cụ thể khác mà bạn muốn dùng.

## 3. **Các nơi khác cần cập nhật khi thay đổi version:**

- **Classifiers** (dòng 17-18): Liệt kê các version Python được hỗ trợ
- **CI/CD workflows** (nếu có trong `.github/workflows/`)
- **Dockerfile** (nếu có)
- **README.md** (documentation)

Bạn muốn update Python version lên version nào? Tôi có thể giúp update tất cả các file cần thiết.
