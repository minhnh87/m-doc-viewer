### Với Zipline-Reloaded (DÙNG CHUNG):

```python
# strategy.py - DÙNG CHO CẢ BACKTEST VÀ LIVE
def initialize(context):
    context.asset = symbol('VNM')

def handle_data(context, data):
    if data.current(context.asset, 'price') > context.sma:
        order(context.asset, 100)  # CÙNG 1 HÀM order()
```

```bash
# Backtest
zipline run -f strategy.py --start 2023-01-01 --end 2024-01-01

# Live trading (cùng file strategy.py)
stratequeue deploy strategy.py --broker ssi --live
```

→ **1 codebase duy nhất**, framework tự handle việc gửi lệnh thật hay giả lập.

## Tại sao quan trọng?

| Vấn đề | Không dùng chung | Dùng chung |
|--------|------------------|------------|
| Backtest lãi, live lỗ | ⚠️ Có thể do code khác | ✅ Ít xảy ra |
| Bug fix | Sửa 2 nơi | Sửa 1 nơi |
| Testing | Test 2 lần | Test 1 lần |
| Confidence | Thấp | Cao |

**Tóm lại:** "Dùng chung code" = viết strategy 1 lần, chạy được cả backtest lẫn live trading mà không cần sửa đổi logic.
