## 1. VectorBT

**Ưu điểm:**
- Tốc độ cực nhanh nhờ NumPy/Pandas + Numba acceleration
- Có thể test hàng triệu strategy variations nhanh chóng
- Flexible với custom data (nhận Pandas DataFrame trực tiếp)
- Tích hợp tốt với data science workflow

**Nhược điểm:**
- Phiên bản Pro có phí (free version giới hạn)
- Không có event-driven mode cho live trading
- Code có thể phức tạp với strategies phức tạp

**Phù hợp:** Research, parameter optimization, rapid prototyping

---

## 2. Backtrader

**Ưu điểm:**
- Architecture event-driven đầy đủ tính năng
- Documentation tốt, community lớn
- Hỗ trợ custom data feeds dễ dàng
- Có thể mở rộng từ backtest sang live trading

**Nhược điểm:**
- Chậm (event-driven loop)
- Development đã chậm lại
- Learning curve cao

**Phù hợp:** Full-fledged strategy architecture, live trading integration

---

## 3. backtesting.py

**Ưu điểm:**
- Lightweight, fast, user-friendly
- Đơn giản, ít boilerplate code
- Nhận Pandas DataFrame trực tiếp
- Interactive charts đẹp

**Nhược điểm:**
- Tính năng hạn chế so với Backtrader
- Không hỗ trợ live trading native

**Phù hợp:** Prototyping nhanh, strategies đơn giản

---

## 4. NautilusTrader

**Ưu điểm:**
- High-performance (Python + Rust core)
- Nanosecond precision data
- **Code backtest = Code live trading** (không cần rewrite)
- Tích hợp AI frameworks tốt

**Nhược điểm:**
- Learning curve rất cao
- Documentation còn hạn chế
- Overkill cho strategies đơn giản

**Phù hợp:** HFT research, production-grade systems, institutional level

---

## 5. LEAN (QuantConnect)

**Ưu điểm:**
- Enterprise-grade, institutional-style structure
- Hỗ trợ C# và Python
- Từ backtest → live trading không cần đổi code
- Multi-asset modeling mạnh

**Nhược điểm:**
- Chậm với swing traders (theo stockanalysis.com)
- Learning curve cao
- Tích hợp custom data phức tạp hơn

**Phù hợp:** Retail quants không muốn build infrastructure riêng

## Khuyến nghị cho trường hợp của bạn

**Yêu cầu:**
- Thị trường VN (cần custom API)
- Nhanh + Chính xác
- Architecture tốt, dễ maintain
- Dễ config

### 🏆 Lựa chọn đề xuất: **Hybrid Approach**

```
Research/Backtest: VectorBT (free) hoặc backtesting.py
Live Trading: Custom implementation hoặc NautilusTrader
```

**Lý do:**

| Yêu cầu | VectorBT | backtesting.py |
|---------|----------|----------------|
| Tốc độ backtest | ✅ Xuất sắc | ✅ Tốt |
| Custom data (VN API) | ✅ Pandas DataFrame | ✅ Pandas DataFrame |
| Dễ config | ✅ | ✅ Rất dễ |
| Dễ maintain | ✅ | ✅ |

### Workflow đề xuất:

1. **Phase 1 - Research:** Dùng **VectorBT** hoặc **backtesting.py** để:
   - Test nhanh nhiều strategy
   - Parameter optimization
   - Walk-forward analysis

2. **Phase 2 - Production:** Build custom trading engine hoặc dùng **NautilusTrader** cho:
   - Live trading
   - Risk management
   - Order execution

### Nếu chỉ chọn 1 thư viện:

- **Ưu tiên tốc độ + research:** → **VectorBT**
- **Ưu tiên đơn giản + nhanh start:** → **backtesting.py**
- **Ưu tiên production-grade + same code backtest/live:** → **NautilusTrader**
