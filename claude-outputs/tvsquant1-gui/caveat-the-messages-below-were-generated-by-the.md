## 🔴 HIGH SEVERITY ISSUES

### 1. **No Tests Written** [HIGH]
**File:** Missing `tests/` directory for story components
**Issue:** Story claims completion but NO unit tests exist for:
- `DropZone.tsx` - drag-drop behavior, validation
- `UploadProgress.tsx` - progress display
- `SymbolList.tsx` - empty state, loading, rendering
- `useUploadData.ts` - mutation behavior, error handling

**Impact:** AC validation cannot be automated; regression risk is high.

### 2. **File Validation Only Checks Extension** [HIGH]
**File:** `DropZone.tsx:34`
```tsx
if (file.name.endsWith('.csv')) {
```
**Issue:** Only validates `.csv` extension, not MIME type. User can rename any file to `.csv` and bypass validation. Should also check `file.type === 'text/csv'` or validate content.

**Impact:** Security - invalid files reach backend, potential crashes or security issues.

### 3. **XHR Missing Abort/Timeout Handling** [HIGH]
**File:** `useUploadData.ts:14-51`
**Issue:** XMLHttpRequest implementation has no:
- Timeout configuration
- Abort capability (no AbortController)
- Timeout event handler

**Impact:** Large files or slow networks can hang indefinitely, blocking UI.

---

## 🟡 MEDIUM SEVERITY ISSUES

### 4. **Missing Error State Reset on New Upload** [MEDIUM]
**File:** `DropZone.tsx:42-48`
```tsx
const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  setValidationError(null)
  const files = e.target.files
  if (files && files[0]) {
    onFileSelect(files[0])
  }
}
```
**Issue:** Input doesn't reset after failed upload. User might see stale file in input. Should reset input value:
```tsx
e.target.value = ''  // Reset input for re-upload of same file
```

### 5. **Hardcoded 100% Progress Before Response** [MEDIUM]
**File:** `useUploadData.ts:22-24`
```tsx
const progress = Math.round((event.loaded / event.total) * 100)
options.onUploadProgress(progress)
```
**Issue:** Progress reaches 100% when upload completes but BEFORE server processes the file. User sees 100% for potentially long server processing time. Should cap at 95% until response:
```tsx
const progress = Math.min(95, Math.round((event.loaded / event.total) * 100))
```

### 6. **Toast Position Conflicts with Upload Progress Card** [MEDIUM]
**File:** `App.tsx:20`
```tsx
<Toaster position="top-right" richColors />
```
**Issue:** Toasts appear top-right while upload progress card is in page flow. On success, both toast AND the green checkmark in UploadProgress show simultaneously, creating redundant feedback.

**Recommendation:** Either:
- Remove success toast (keep only error toast)
- OR hide UploadProgress on success after delay

xhr.open('POST', `${API_URL}/data/upload`)
