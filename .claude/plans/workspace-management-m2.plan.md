## Tasks

### Task 1: `workspace-tabs.js` module
- `renderWorkspaceTabs()` — đọc workspaces, render vào `#workspace-tabs`, gắn click listener.
- Click tab → `setActiveWorkspaceId(id)` + `loadFileTree()` (re-render tree với folder của ws mới).
- Highlight tab active dựa `getActiveWorkspaceId()`.
- M2 chỉ render tab read-only; CRUD UI là M3 (chỉ cần Default tab visible khi mới migrate).

### Task 2: Update `file-tree.js`
- Replace `import { getExternalFolders, removeExternalFolder } from './storage.js';` → import từ `./workspaces.js`: `getActiveWorkspaceFolders`, `removeFolderFromWorkspace`, `getActiveWorkspaceId`.
- `loadFileTree()`: `const externalFolders = getActiveWorkspaceFolders();` thay vì `getExternalFolders()`.
- `remove-external-btn` handler: `removeFolderFromWorkspace(getActiveWorkspaceId(), path)` thay vì `removeExternalFolder(path)`.

### Task 3: Update `dialogs.js` (Add external folder flow)
- Tìm chỗ gọi `addExternalFolder(path)` (từ `storage.js`).
- Replace bằng `addFolderToWorkspace(getActiveWorkspaceId(), path)`.

### Task 4: HTML + CSS
- `index.html`: thêm `<div id="workspace-tabs" class="workspace-tabs"></div>` ngay trong `.file-tree-header`, **trên** `.file-tree-header-row`.
- `styles.css`: 
  - `.workspace-tabs` — flex row, scroll-x nếu nhiều tab, border-bottom subtle.
  - `.workspace-tab` — padding, cursor pointer, hover `--bg-hover`.
  - `.workspace-tab.active` — `--bg-tertiary` background, font-weight tăng.
  - Match dark theme qua existing CSS vars.

### Task 5: Wire trong `view.js`
- Import `renderWorkspaceTabs` từ `./modules/workspace-tabs.js`.
- Gọi `renderWorkspaceTabs()` trước `loadFileTree()`.

## Validation

Manual smoke flow trong browser sau khi `npm start`:
1. Page load → tab bar hiển thị 1 tab "Default" (active).
2. File tree render folder migration từ `externalFolders` cũ (giống M1 đảm bảo).
3. DevTools: `(await import('/modules/workspaces.js')).createWorkspace('Research')` → reload page → tab "Research" hiển thị bên cạnh Default.
4. Click "Research" → tab Research active, file tree rỗng (vì ws mới).
5. Click "Add external folder" button → thêm folder → folder hiện ra trong tab Research; switch sang Default → folder đó không có.
6. Reload → active workspace + folder mapping vẫn restore đúng.

```bash
node --check public/modules/workspace-tabs.js
```
